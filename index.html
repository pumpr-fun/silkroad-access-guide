ROUTE 02 // OTHER OPTIONS

Can Tor run inside this website?

Not safely. Vercel and ordinary browsers use the public internet; JavaScript cannot create a Tor circuit or resolve an onion address. The private site also cannot be framed here because the guide blocks frames and the onion service is a separate security origin.

ROUTE 03 // SECURITY CHECK

Know what Tor protects—and what it does not.

01

Verify all 56 characters

Modern v3 onion addresses contain 56 letters and numbers before .onion. Short 16-character v2 addresses no longer work.

02

Use the onion icon

Tor Browser shows an onion indicator in the address bar when the connection is using an onion service.

03

Keep Tor Browser updated

Install updates promptly and download installers only from Tor Project or its documented official distribution routes.

04

Avoid extra extensions

Add-ons can change the browser fingerprint or observe activity. Keep the browser close to its default configuration.

05

Separate identities

Tor cannot undo personal details you voluntarily share. Do not mix accounts or identifying information across contexts.

06

Use bridges when blocked

In Tor Browser, open Settings → Connection → Bridges. Request a bridge or select a built-in transport such as Snowflake.

ROUTE 04 // TROUBLESHOOTING

If the route does not open.

Tor Browser says the onion site cannot be found.

First compare the entire address with the verified address on this page. If it matches, wait a few minutes and retry; the onion service or its host may temporarily be offline.

Tor does not connect on my network.

Select “Configure Connection,” then enable a bridge. Tor Project documents built-in transports and bridge requests for networks that block Tor.

The address opens in Chrome or another regular browser.

A normal browser does not natively resolve onion services. If a third party opens it, that party is acting as a gateway. Close it and use Tor Browser for the intended privacy model.

The page looks different from the one I used before.

Stop and re-check the address. Do not enter credentials until the exact v3 address matches. Interface changes alone are not proof of authenticity.
